## 자주 틀리는 표기

- 첫 인사 자기소개 문맥의 `진호`, `진우`, `지노`, `디노`, `DINO`, `Dino`, `DENO` -> `Deno`
- Turbo LoRA와 함께 최적화 기법으로 언급되는 `스펙트럼` -> `Spectrum`
- `512 곱하기 512` -> `512 x 512`
- `개발자님이`가 문맥상 사람 호칭이면 `KJ형님이` 가능성 우선 확인
- `컴퓨터`가 문맥상 ComfyUI이면 `ComfyUI`
- `지피티`, `책도서`, `최지피티` -> `ChatGPT`
- `로라` -> `LoRA`
- `시그마` -> `sigma`
- `디노이즈` -> `denoise`
