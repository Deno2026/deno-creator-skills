# Premiere UXP Tool Coverage

기준 버전: Premiere Pro UXP 26.3

이 문서는 `servers/premiere-uxp-mcp/schemas/upstream-tools.json`의 266개 도구를 공식 API 근거와 함께 분류한다. 현재 호출 경로와 runtime 상태는 `servers/premiere-uxp-mcp/capabilities.json`이 소유한다. `ported-caveat` handler는 bounded 실행 후 결과를 read-back한다.

## Coverage summary

| Status | Count | Definition |
| --- | ---: | --- |
| `ported` | 13 | live UXP roundtrip 근거가 있는 handler |
| `ported-caveat` | 183 | 공식 UXP API로 구현·offline 검증된 handler; bounded 실행과 read-back 사용 |
| `blocked-uxp` | 56 | 공식 UXP API가 없거나 upstream 의미를 보존할 수 없는 도구 |
| `deferred` | 14 | atomicity·schema·외부 실행 계약을 완성해야 등록할 수 있는 도구 |
| **Total** | **266** | upstream schema 전체; 중복·누락 없음 |

## Runtime 상태

- 현재 registry의 live 근거와 실행 route는 `servers/premiere-uxp-mcp/capabilities.json`에서 조회한다.
- `get_work_area`는 UXP와 CEP에서 재현되는 runtime failure로 현재 unavailable이다.
- `undo`는 공식 UXP API가 없고 Premiere 26.3.2 CEP도 지원하지 않아 현재 unavailable이다.
- `ported-caveat`는 공식 handler를 실행하고 read-back한다. `local-unverified`는 bounded diagnostic project에서 `--allow-experimental`로 실행한다.
- 일반 쓰기는 `--allow-write`, 위험 작업은 `--allow-write --allow-dangerous`를 사용한다.

## Cross-cutting compatibility and safety

- Stable TrackItem ID: 공식 API가 node ID getter를 제공하지 않아 handler는 `uxp:<trackType>:<trackIndex>:<clipIndex>:<projectItemId>:<startTicks>`를 합성한다. 편집 후에는 현재 구조에서 ID를 다시 읽는다.
- Track lock state: Premiere 26.3 공식 UXP API는 video/audio track lock getter를 제공하지 않는다. 트랙·시퀀스 응답은 `locked`/`isLocked`에 `null`을 반환한다.
- Action vs direct write: Action을 제공하는 API는 `Project.lockedAccess()` + `Project.executeTransaction(..., "DENO: <command>")`으로 묶을 수 있다. `Project.importFiles()`, `Sequence.setPlayerPosition()`, `Track.setMute()`, `ClipProjectItem.changeMediaFilePath()`, Source Monitor, project lifecycle, Encoder/Exporter, MOGRT insertion 같은 direct API는 동일한 Undo 보장이 없다.
- Localized ComponentParam: Component에는 `getMatchName()`이 있지만 parameter에는 localized `displayName`만 있다. Motion/Opacity/audio 속성은 한국어 alias와 실제 runtime 이름을 읽은 뒤 쓰며, 임의 index 고정은 금지한다.
- Transition identity: `TransitionFactory`는 video transition `matchName`을 열거·생성한다. CEP의 localized display name과 다를 수 있으므로 runtime alias/parity 검증이 필요하다.
- `capture_frame`: UXP 대안은 `Exporter.exportSequenceFrame()`으로 sequence frame을 플러그인 전용 임시 폴더에 내보내고, MCP가 검증·반환한 뒤 즉시 삭제하는 read-only temporary capture다. 프로젝트나 사용자 출력물을 바꾸지 않으며, CEP의 Windows PrintWindow 전체 Premiere 창 캡처와 의미가 다르다.
- Permission gate: 일반 timeline 쓰기는 `--allow-write`를 사용한다. 프로젝트 lifecycle·project item 삭제·export/encode·relink/offline·global preference 작업은 `--allow-write --allow-dangerous`를 사용한다. 서버는 bridge 요청 생성 전에 두 flag를 확인한다.
- Local schema overrides: CEP 설명과 공식 UXP 계약이 다르거나 안전한 non-noop 제약이 필요한 도구는 `schemas/local-tools.json`의 `overrides`에 이유와 UXP 입력 계약을 명시한다. Override는 대응 upstream/local 도구의 입력 계약으로 집계한다.
