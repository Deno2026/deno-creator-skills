# 모션 제작 원칙(엔진 공통)

Remotion이든 After Effects든 같은 네 모듈로 만들고 검수한다. 연출 취향이 아니라 **움직임이 읽히는 조건**이다.

## 1. 구조

- 장면은 `등장 → 변화 → 읽는 시간 → 퇴장`의 네 사건으로 짠다. 사건마다 시작 프레임과 길이를 정해 두고, 발화의 핵심 명사·숫자가 처음 보이는 프레임을 cue 시작에 착지시킨다.
- 한 장면에 동시에 움직이는 주인공은 하나다. 나머지는 정지하거나 아주 느리게 따라간다.
- 계층(부모·자식) 관계로 묶어서 움직인다. 카드 안의 글자를 카드와 따로 움직이지 않는다.

## 2. 운동

- 가속·감속(ease)은 사건의 의미에 맞춘다: 등장은 빠르게 들어와 천천히 멈추고(ease-out), 퇴장은 천천히 시작해 빠르게 빠진다(ease-in). 선형 이동은 기계적인 것에만.
- 위치·크기·회전·불투명도를 한꺼번에 바꾸지 않는다. 두 축까지.
- 접점(닿는 순간)과 정착(멈추는 순간)은 프레임 단위로 확인한다. 오버슈트를 쓰면 되돌아오는 길이는 나간 길이의 1/3 이하.
- 카메라(전체 이동·줌)는 장면당 한 번, 사용자가 원할 때만.

## 3. 타이포그래피

- 문구는 짧고 굵게, 위계는 두 축 이상으로 구분한다([서체](motion-typography.md)).
- 글자는 등장 뒤 읽을 시간을 준다: 단어 수 × 0.3초에 0.5초를 더한 값을 최소로.
- 같은 자리에서 문구를 바꿀 때는 나간 뒤 들어온다. 겹쳐 페이드하지 않는다.
- 자막 자리·액자 띠·UI의 중요한 부분은 가리지 않는다(보호 영역).

## 4. 검수

- 정지 프레임으로 공간(위치·여백·겹침)을, 연속 프레임으로 이동·접점·전환을, 오디오와 함께 실제 속도로 의미(발화와의 결속)를 본다. 셋 다 한 뒤에만 "됐다"고 말한다.
- 렌더 결과(파일)로 검수한다. 코드나 설정값을 읽은 것으로 대신하지 않는다.
- 출력 FPS를 바꾸기 전에 시간 곡선·모션 블러·샘플 시각을 확인하고 실제 렌더로 비교한다.
- 남은 한계(못 맞춘 프레임·근사한 부분)는 검수 노트에 적는다.
