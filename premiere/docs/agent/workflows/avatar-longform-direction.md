# 진행자(아바타) 장면 프로필 — 내 채널의 것

강의·설명형 롱폼에 진행자(실사 또는 생성 아바타)가 나온다면 그 장면의 기준을 여기에 적는다. 키트는 기본값을 주지 않는다. 진행자 원본 클립의 생성은 창작 상류(`local.config.json` `creativeUpstreamRoot`)의 몫이고, 이 문서는 후반에서 진행자 샷을 어디에 어떻게 두는지만 다룬다.

에이전트에게: 이 문서가 비어 있으면 진행자 샷을 강제하지 않는다. 자료·결과·UI가 필요한 구간은 발화에 따라 전환하고, 모든 초에 진행자를 넣지 않는다. 사용자가 정한 것만 아래에 기록한다.
