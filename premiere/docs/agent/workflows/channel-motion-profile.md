# 채널 연출 기준 — 내 채널의 것

이 문서는 **비어 있는 틀**이다. 연출(색·서체 조합·장면 리듬·덮개 불투명도·자료 배치 습관)은 키트가 정하지 않는다. 첫 영상에서 에이전트와 대화하며 정하고, 사용자가 좋다고 한 것만 여기에 적는다. 적힌 것은 다음 영상의 기본값이 되고, 사용자가 바꾸면 여기서 바꾼다.

에이전트에게: 이 문서가 비어 있으면 [모션 제작](motion-production.md)의 절차대로 진행하되, 첫 결정마다 2~3안을 실제 렌더로 비교해 보여 주고 사용자가 고른 것을 아래 표에 기록한다. 채워진 항목은 묻지 않고 적용한다.
