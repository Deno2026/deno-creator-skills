# 키트 교차 에이전트 검사 — 2026-09-07

키트 0.1.0 초안이 "어떤 에이전트도 같은 문서를 같은 순서로 본다"는 목표를 실제로 지키는지
실측한 기록이다. 같은 과제(예제 작품 「새벽 빵집」 C01을 MiniMax H3 R2V로 만들 준비, 생성은
하지 않음, 외부 연결 없음)를 에이전트마다 새 문맥으로 주고, 읽은 파일 순서·실행한 명령·게이트
결과를 비교했다.

## 방법 메모

- 코덱스는 `~/.codex/config.toml`의 기본 설정(`sandbox_mode = "danger-full-access"`)으로 돌렸다.
  `--sandbox read-only`를 붙이면 이 PC에서는 윈도우 격리가 프로세스 생성을 거부해 명령이
  전부 실패한다. 읽기 전용은 프롬프트로 못 박았고 실제로 리포 변경은 없었다.
- 프롬프트는 세 에이전트에 같은 파일(`p_kit.txt`)을 줬다. 클로드 하위 에이전트에는 "이 폴더에서
  열린 에이전트처럼 진입 파일부터 읽으라"는 문장을 덧붙였다(하네스가 다른 프로젝트 지침을
  자동 주입하는 것을 무시하게 하려고).
