# 키트 교차 에이전트 검사 — 2026-09-07

키트 0.1.0 초안이 "어떤 에이전트도 같은 문서를 같은 순서로 본다"는 목표를 실제로 지키는지
실측한 기록이다. 같은 과제(예제 작품 「새벽 빵집」 C01을 MiniMax H3 R2V로 만들 준비, 생성은
하지 않음)를 에이전트마다 새 문맥으로 주고, 읽은 파일 순서·실행한 명령·게이트 결과를 비교한다.

## 클로드 코드 하위 에이전트 (완료)

- **읽은 순서**: `CLAUDE.md` → `AGENTS.md` → `docs/routes.json` → `craft/gate.md` →
  `craft/doctrine.md` → `craft/taste.md` → `craft/guides/minimax-h3-r2v.md` → 작품 `BRIEF.md` →
  `STATE.md`. 작업 유형 표의 `read_order`와 **정확히 같은 순서**. 그 뒤 게이트 항목의 소유 문서로
  지목된 `DECISIONS.md`, `scenes/C01.md`, `assets/README.md`, `craft/guides/image-assets.md`와
  템플릿 README들을 추가로 읽었다(폴더 모양·이름 규약 대조 목적). 폴더 밖 파일·사설 메모리는 열지 않음.
- **라우터**: `tools/route.py --task generate-video --project … --model minimax-h3-r2v` 실행 결과가
  `routes.json` 손읽기와 동일. `--check` PASS.
- **게이트 결과**: G1·G2·G3·G5·G7 ✔ / G6 부분(서버 대조 불가) / G8 확인 불가 / G9 해당없음 /
  **G4 ✖(앵커·참조 이미지 부재, 감독 미확인) · G10 미수행(읽기 전용)** → "생성 불가"를 결과로 보고.
  되는 조건으로 바꾸지 않았다.
- **지적한 빈틈과 반영**:

| 지적 | 반영(0.1.0 → 커밋) |
|---|---|
| 예제 작품에 `renders/`·`review/`·`assets/anchors|refs|boards/` 폴더 없음(빈 폴더는 Git이 안 담음) | 예제·템플릿에 `.gitkeep`·README 추가, `route.py --check`가 작품 폴더 모양과 STATE 머리 세 줄을 검사 |
| 앵커 이름 규약이 BRIEF·C01(`owner_v1.png`) vs 템플릿·가이드(`C01_anchor_v1.png`)로 다름, "클립마다 앵커" vs 인물 1장 | `image-assets.md`에 투입 자산 3종(정체성 기준·클립 앵커·장소 참조)과 이름 규약을 표로 확정, 예제 문서 전부 맞춤 |
| 저해상도 확인 판의 값이 어디에도 없음 | H3 가이드에 「확인 판」 절(절반 해상도 384×672, 서버 허용 목록 우선), 게이트 G3이 그 절을 가리킴 |
| 시드 기록 시점(랜덤이면 값이 없음) | 게이트 G10·가이드: `랜덤`이라 적고 회수 때 실제 값으로 |
| 프롬프트 언어 미지정 | 가이드: 본문 영어, 한국어 대사만 태그 안. 예제 C01 입력을 영어로 |
| DECISIONS가 "전역" 층이라 했는데 취향 장부는 비어 있음 | 예제 결정을 "작품" 층으로 정정("앞으로 계속"은 감독이 말할 때 승격) |
| 중간 보고 형식이 `docs/session.md`에만 있어 generate 유형은 못 봄 | `AGENTS.md` 「역할과 결정권」에 3요소 한 줄 추가 |
| 비용 정보의 소유 문서 없음 | 게이트 G9: 서버 안내에서 그때 확인 |

| 카메라 문구 "고정된 채 다가간다"의 모호함 | 가이드: 카메라는 한 문장에 한 동작. 예제 문구 수정 |

## 코덱스 CLI (GPT-6 Astra, xhigh) — 보류

이 PC의 코덱스 CLI 샌드박스가 프로세스 생성을 거부해(`CreateProcessAsUserW failed: 5`) 명령을
못 돌리는 상태라, 감독이 코덱스 앱을 재시작한 뒤 다시 돌린다. 파일 읽기만으로도 표를 손으로
읽어 같은 목록에 도달하는지가 확인 대상이다.
