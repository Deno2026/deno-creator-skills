# productions — 작품 폴더

작품 하나 = `productions/<날짜_제목>/` 하나. 기록은 Git에, 생성 파일은 `renders/`에(Git 제외). 두 파일이 뼈대다.

## BRIEF.md — 목적과 방향 (사용자와 정한 것)

- 무엇을 만드나(한 줄)
- 누가 보나, 어디에 올리나
- 보여 줄 것의 순서(줄거리·구성)
- 톤·호흡·표현 — 사용자가 정한 것. 꾸러미의 예시를 그대로 따르지 않는다
- 쓰는 꾸러미와 판

## 상태.md — 진행 상태 (새 세션이 이어받는 자리)

- 상태: 진행 중 | 확인 대기 | 완료
- 지금까지 한 것 / 지금 하는 것 / 다음 행동
- 사용자가 정한 결정(날짜와 함께)
- 열린 질문

긴 작업은 상태.md를 먼저 갱신하고 새 세션에서 이어받는다 — 대화가 길수록 품질이 떨어진다.
