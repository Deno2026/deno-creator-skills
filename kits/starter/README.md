# 이 작업장 사용법

AI 에이전트(클로드 코드·코덱스 등)와 함께 영상·이미지를 만드는 작업장입니다. 구조와 일하는 순서는 DenoMCP 스타터 킷이 잡았고,
무엇을 어떻게 만들지는 당신이 정합니다. 에이전트는 갈림길마다 당신에게 묻습니다.

## 에이전트에게 이렇게 말하면 됩니다

- "DenoMCP로 뭘 할 수 있어?" — 지금 쓸 수 있는 것 안내
- "디노 스킬 뭐 있어?" / "교육숏츠 꾸러미 들여줘" — 제작 방법(꾸러미) 목록과 들이기
- "내 주제로 하나 만들자" — 작품 폴더를 만들고, 목적과 방향을 묻는 것부터 시작
- "디노 업데이트 있어?" — 들인 꾸러미에 바뀐 점이 있는지 비교해서 보여 줌
- "상태 정리하고 마무리하자" — 긴 작업은 상태 파일에 적고 다음 세션에서 이어받기

## 폴더

- `AGENTS.md` — 에이전트가 따르는 뼈대(순서·어디서 묻는지·넘지 않는 선)
- `docs/agent/routes.json` — 작업 유형별로 먼저 읽을 문서
- `skills/` — 들여온 꾸러미와 장부(`deno-kit.json`)
- `productions/` — 작품 하나에 폴더 하나(`BRIEF.md` 목적·방향, `상태.md` 진행 상태, `renders/` 생성 파일)
- `_scratch/` — 임시

## 한 번만 할 것

- 파이썬이 없으면 `.codex/hooks.json`·`.claude/settings.json`은 빼도 됩니다.
