# scenes — 클립별 지시서

클립마다 파일 하나(`C01.md`, `C02.md`…). 모델 입력 원문과 그 클립만의 시도를 적는다.

```markdown
# C01 — (클립 한 줄 설명)

- 모델: minimax-h3-r2v
- 앵커/참조: assets/anchors/C01_anchor_v1.png (얼굴·헤어·의상), assets/refs/space_v1.png (장소만)
- 길이·해상도: 5초 (124프레임) · 768×1344

## 입력 원문
(여섯 칸 프롬프트 그대로)

## 이번 판만의 시도
- v2: 카메라를 눈높이로 낮춤 (클립 한정, 문서에 반영하지 않음)
```
