# 작품 폴더 템플릿

새 작품은 이 폴더를 통째로 복사해 `projects/<날짜>_<작품이름>/`으로 만든다. 폴더 모양은
바꾸지 않는다. 다른 에이전트가 와도 같은 자리에서 같은 것을 찾아야 한다.

```text
projects/2026-09-07_첫-작품/
├── BRIEF.md        확정 내용 — 무엇을 만드는가 (감독이 고른 것만)
├── STATE.md        지금 어디까지 — 상태·마지막 갱신·다음 행동
├── DECISIONS.md    무엇을 왜 정했나 — 고른 것, 버린 것, 이유, 날짜
├── scenes/         클립별 지시서 (모델 입력 원문). 예: C01.md, C02.md
├── assets/         투입·컨펌 이미지 — anchors/ refs/ boards/
├── renders/        생성 결과. 판 이름·시드를 파일 이름에 (Git 추적 안 함)
└── review/         비교 이미지, 검수 표, 감독 전달본
```

- `BRIEF.md`는 감독이 고른 것만 담는다. 고르지 않은 후보는 `DECISIONS.md`에 "버림"으로.
- `STATE.md` 머리 세 줄(`상태`, `마지막 갱신`, `다음 행동`)은 항상 현재여야 한다.
- 클립 하나만의 시도는 `scenes/`의 그 클립 파일에만 적는다. 문서를 건드리지 않는다.
