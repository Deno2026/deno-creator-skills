# 모델 가이드

| 항목 | 내용 |
|---|---|
| 목적 | 모델마다 입력 형식·고정값·함정을 한 파일에 둔다. 생성 전에 반드시 읽는다. |
| 적용 조건 | `generate-video`, `generate-image` 작업 유형 |
| 관련 문서 | [생성 전 게이트](../gate.md) · [공통 연출 교리](../doctrine.md) |

## 규칙

- **가이드를 읽기 전에 생성하지 않는다.** 감으로 쓰면 판마다 비용이 나가고 개선도 수렴하지
  않는다. 새 모델을 쓰게 되면 공식 프롬프트 가이드를 먼저 찾아 이 폴더에 가이드 파일을 만든다.
- 가이드는 **현재 확정값만** 담는다. 실측으로 값이 바뀌면 옛 값을 지우고 새 값만 남긴다.
- MCP 서버가 알려주는 입력 요구(`input_requirements`)가 가이드보다 최신이면 서버가 이기고,
  가이드를 고쳐야 한다고 감독에게 보고한다.
- 서로 다른 모델의 수치와 성공 사례를 추측으로 섞지 않는다.

## 파일

| 파일 | 모델 | 용도 |
|---|---|---|
| [minimax-h3-r2v.md](minimax-h3-r2v.md) | MiniMax H3 R2V (참고물 → 영상) | 인물·화풍·사물 참조로 새 장면 |
| [image-assets.md](image-assets.md) | 이미지 생성 전반 | 앵커·참조 이미지·클린 에셋 |

새 모델은 이 표에 한 줄 추가하고 같은 틀(목적·입력 형식·고정값·함정·검사)로 파일을 만든다.
