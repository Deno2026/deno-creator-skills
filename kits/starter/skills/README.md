# skills — DenoMCP에서 들여온 제작 방법(꾸러미)

- 한 꾸러미 한 파일: `<slug>.md` (`deno_knowhow_get`이 준 그대로). 들인 것은 `deno-kit.json`(장부)에 한 줄씩 — 이름·판·들인 날·통째로(whole)/골라서(partial).
- 꾸러미가 주는 것은 **목적과 진행 순서**다: 이 워크플로가 무엇을 위한 것인지, 어떤 단계로 가는지, 각 단계에서 사용자와 무엇을 정하는지.
- 꾸러미의 「디노는 이렇게 한다」는 예시다. 표현·호흡·분위기·수치 같은 취향은 사용자가 정하고, 사용자가 이미 자기 방식이 있으면 그것이 우선이다.
- 첨부 파일(워크플로 JSON·도구 스크립트)은 `deno_knowhow_get`의 `files` 주소에서 받아 `<slug>/` 폴더에 같은 이름으로 둔다. 판이 바뀌면 첨부의 sha256도 바뀐다.
- 업데이트는 사용자가 물을 때 장부의 판과 서버의 판을 비교해 바뀐 점만 보여 주고, 고른 것만 갱신한다. 파일을 덮어쓸 때는 장부의 판도 올린다.
