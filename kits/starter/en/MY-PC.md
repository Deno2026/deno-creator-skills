# MY-PC — this PC's fixed values

The ledger the agent reads first before making anything in your own ComfyUI. When it is empty, fill it in the order of the `comfyui-fit-my-pc` package
(read the hardware → smoke test → ladder → decide with the user) and write down only the decided values. The numbers in Deno's packages are examples from Deno's PC.
Measure again only in three cases — a new GPU or RAM, a new model or workflow, or when the user asks.
