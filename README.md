# Deno Director MCP

Deno MCP(denomcp.com)의 공개 키트 저장소. 에이전트(클로드 코드, 코덱스 등 MCP를 지원하는 에이전트)에
붙여 넣기 한 번으로 **감독의 작업실**을 세우는 셋업 워크플로우와, 그 작업실이 따르는 문서·워크플로를 담는다.

- `kit/` — 셋업이 내려주는 파일 묶음(AGENTS.md 정본, 라우팅, 교리, 모델별 프롬프트 가이드, 작품 폴더 템플릿)
- `workflows/` — 로컬에서 직접 돌리는 사람을 위한 ComfyUI 워크플로 JSON
- `plugin/` — 클로드 코드 플러그인 정의(MCP 연결 + 스킬 한 번에 설치)

상태: 비공개 준비 중. `kit/`은 0.1.0 초안이 채워졌다(2026-09-07, 정본·작업 유형 표·게이트·교리·취향 장부·모델 가이드·작품 템플릿·예제·라우터). 내용이 채워지면 공개한다. 노하우·워크플로우·문서는 출처(Deno MCP, denomcp.com) 표기 조건으로
자유롭게 사용·수정·재배포할 수 있다(CC BY 4.0 취지). 코드 라이선스는 공개 전 확정.

## 이름과 자리

- **Deno Director MCP**: 사이트의 약속 "이것만 연결하면 당신의 에이전트는 유능한 스태프가 되고, 당신은 감독이
  됩니다"와 한 몸인 이름이다. 제품·사이트 이름은 **Deno MCP**로 유지하고, 이 저장소는 그 키트를 담는다.
- 저장소: https://github.com/Deno2026/deno-director-mcp (비공개, 내용이 차면 공개). 로컬 `E:\DENO-Repos\deno-director-mcp`.

## 넣지 않는 것

- 게이트웨이 서버 코드, 접속 키, 내부 운영 규칙, 디노 발언 인용, 로컬 경로·계정 상태.
- 렌더 원본(mp4·wav)과 비밀 파일(`.gitignore`).

## 남은 일

- 게이트웨이에 `setup`(키트 내려주기)·`kit_update`(갱신) 도구 — 사이트가 약속한 "붙여 넣기 한 번" 실현.
- 코드 라이선스 확정(기본은 GPL-3.0-only, 디노 결정 대기). 공개 전환 시점.
- Gemini·Cursor·Hermes·OpenClaw가 진입 표지판을 실제로 자동 적재하는지 실측.
