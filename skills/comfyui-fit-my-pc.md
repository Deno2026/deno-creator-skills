# 내 PC에 맞는 설정값 찾기

디노의 워크플로 꾸러미에 적힌 수치(H3 1088p급, Qwen 2K·CFG 2·40스텝 …)는 **디노 PC(RTX PRO 6000, VRAM 96GB) 기준의 최고 품질 권장값**이다.
그 값은 여전히 기준점이지만 「그 PC에서 최적이었다」는 뜻이지 모든 PC의 시작값이 아니다. 에이전트는 사용자 PC에서 **작게 한 번 돌려 보고(스모크 테스트) →
되는 만큼 올리고 → 사용자와 정하고 → 고정**한다(디노 확정 2026-09-27). 이 편은 그 절차 하나만 담는다.

## 무엇을 만드나

- 사용자 PC 전용 **설정 장부 한 장**(`MY-PC.md`): 워크플로별 고정값(크기·길이·화질 단계·스텝·CFG·기동 인자)과 근거(스모크 결과 — 완주 여부·걸린 시간·VRAM 피크·날짜).
- 결과 예(디노 실측): VRAM 16GB 카드(RTX 4060 Ti)는 H3 R2V 864×480·5초 초안이 약 2분 45초(2026-09-26), 1344×768·10초 본 판이 약 17분(2026-09-03, 당시 그래프)이고 15초 단일 패스는 메모리 부족 — 그래서 그 PC의 고정값은 「768p·5~10초」가 된다. 96GB 카드는 1344×768·15초가 약 8분이라 1088p급이 고정값이다.

## 목적

- 디노 값을 그대로 돌리면 대부분의 PC에서 메모리 부족, 수십 분 대기, 또는 윈도우의 시스템 메모리 폴백(오류 없이 기어감)에 걸린다. 사용자 PC에서 되는 값을 **한 번** 찾아 고정하면 그 뒤로는 판마다 고민하지 않고, 사용자도 매번 질문받지 않는다.
- 스모크 테스트를 실제 재료로 하면 방향 확인(구도·대사·화풍)까지 같이 끝난다 — 시간만 재는 빈 판을 만들지 않는다.

## 진행 순서와 갈림길

1. **장비를 읽는다.** `/system_stats`에서 GPU 이름·VRAM 총량·여유, 시스템 RAM을 적는다(`comfyui-agent-basics`). 이미 `MY-PC.md`가 있고 GPU가 같으면 3~5를 건너뛰고 고정값으로 간다.
2. **스모크 테스트 기준(디노 확정 2026-09-27).** 정본 그래프를 그대로 두고(스텝·로라·시드·CFG 유지) 크기·길이만 작게:
   - 영상(MiniMax H3, `minimax-h3-r2v-deno`): **5초**(124프레임)·초안 크기(짧은 변 480, 예 864×480). 5초보다 짧은 판은 만들지 않는다(학습 범위 밖).
   - 사진(Qwen-Image 2.1, `qwen-image-21-t2i-edit`): **1080p급**(약 2MP, 예 1920×1088 또는 프롬프팅 꾸러미 크기표의 2MP 줄)·CFG 2.0·40스텝.
   - 프롬프트·참고는 실제로 쓸 것으로 넣는다. 결과도 사용자에게 보인다(방향 확인을 겸한다).
3. **판정 셋.** 완주했나 · 걸린 시간(서버 로그 `Prompt executed in N seconds`) · VRAM 피크와 폴백 징후(`nvidia-smi`: GPU 사용률이 낮은데 「공유 GPU 메모리」가 크면 시스템 메모리로 넘친 것 — 완주해도 **실패**로 친다). 화질 이상(깨짐·반복 무늬)도 실패.
4. **사다리 — 한 번에 한 칸만.**
   - 되면 올린다: H3는 크기 먼저(480 → 768 → 1088p급), 그다음 길이(5 → 10 → 15초). Qwen은 1080p급 → 2K(약 4MP).
   - H3 잠재 업스케일 구성(7+1·8+1)은 손잡이가 둘이다(디노 확정 2026-09-27): **시작 해상도**를 먼저 정하고(그 PC에서 8스텝이 완주하는 가장 큰 크기, 되도록 짧은 변 768 근처 — 너무 낮게 시작하면 업스케일해도 디테일이 안 산다) → **배수**는 ×1.5부터, 되면 ×2. 업스케일 뒤는 1스텝뿐이지만 그 단계의 VRAM이 최종 크기 × 프레임에 비례해 가장 크므로, 마지막 스텝이 메모리 부족·기어감이면 배수를 내리거나 길이를 줄인다. 원칙은 `minimax-h3-r2v-deno` 「잠재 업스케일의 두 손잡이」.
   - 안 되면 내린다: H3는 길이를 먼저 줄이고(이미 5초면 크기를 내린다), Qwen은 2MP → 1MP(1344×768급). 기동 인자(`--vram-headroom`·pinned·`--fast` 금지)는 `comfyui-agent-basics` 함정 절.
   - 칸마다 시간·피크·완주를 적는다. 보통 3~5판이면 끝난다. 사용자가 「대충 빨리」를 원하면 첫 완주 칸에서 멈춘다.
5. **사용자에게 묻는다 — 사다리를 다 돈 뒤 한 번.** 2~3안(빠름 / 균형 / 최고)을 시간·화질 예상과 함께 보이고 추천 하나를 단다. 스모크 판마다 묻지 않는다.
6. **결정되면 고정한다.** 프로젝트 루트 `MY-PC.md`에 「이 PC의 고정값」으로 적고(아래 양식), 스타터 킷 v8부터는 `AGENTS.md`와 `MY-PC.md` 틀이 이미 들어 있으니 그 틀을 채우면 된다(그 전 킷이면 사용자 동의 아래 `AGENTS.md`에 「생성 전 `MY-PC.md`의 고정값을 쓴다」 한 줄을 더한다). 그 뒤 모든 판은 이 값으로만 돌린다. 다시 스모크하는 경우는 셋뿐 — GPU·RAM 교체, 모델·워크플로 교체, 사용자 요청.

## 내용 자리 — 사용자가 채우는 칸 (`MY-PC.md` 양식)

```markdown
# MY-PC — 이 PC의 고정값

| 항목 | 값 |
|---|---|
| PC / GPU / VRAM / RAM | 예: 데스크탑 / RTX 4060 Ti / 16GB / 32GB |
| ComfyUI / 기동 인자 | 예: 데스크탑 앱 0.37.4 / --enable-manager --use-ck-attention |

| 워크플로 | 고정값 | 스모크 근거(날짜 · 시간 · VRAM 피크 · 완주) | 정한 사람·날짜 |
|---|---|---|---|
| MiniMax H3 R2V | 1344×768 · 10초 · native 8스텝 | 2026-09-27 · 17분 · 15.0GB · 완주 | 사용자 · 2026-09-27 |
| Qwen-Image 2.1 | 1920×1088 · CFG 2.0 · 40스텝 | 2026-09-27 · 25초 · 12.1GB · 완주 | 사용자 · 2026-09-27 |
```

표의 값은 자리표시 예시다 — 사용자 PC의 측정으로 바꾼다.

## 실행 — 로컬(내 ComfyUI)

- 스모크 판 만들기: H3는 `minimax-h3-r2v-deno` 실행 절의 API 그래프에서 크기 노드(`DenoResolutionSetup` 또는 잠재 크기)와 `length`만 바꾼다. Qwen은 `qwen-image-21-t2i-edit`의 크기 노드 `10`(`width/height`)만 바꾼다. 다른 값은 건드리지 않는다 — 스텝·CFG를 같이 바꾸면 무엇 때문에 됐는지 모른다.
- 측정: 접수 전후 `/system_stats`의 `vram_free`, 완료 뒤 서버 로그의 실행 시간, 도는 동안 `nvidia-smi --query-gpu=utilization.gpu,memory.used --format=csv -l 5`.
- 윈도우 NVIDIA의 시스템 메모리 폴백은 메모리 부족 오류 대신 「느려짐」으로 나타난다 — 시간이 평소의 몇 배면 피크를 보고 실패로 판정한다(`comfyui-agent-basics` 함정 절).
- 5초 H3 판이 16GB에서도 2~3분이면 정상 범위다. 그보다 훨씬 길면 폴백·다른 프로세스(브라우저·다른 모델)를 먼저 의심한다.

## 디노는 이렇게 한다 — 예시 (참고이지 기준이 아니다)

- **디노 PC(96GB) 고정값**: H3 R2V는 1088p급(기본 7+1 15초 약 6분 반 / 액션 8+1 15초 약 12분 반); Qwen은 네이티브 2K·CFG 2.0·40스텝(1344×768 40스텝 8.9초). 이 값이 각 꾸러미의 「디노는 이렇게 한다」에 있다.
- **디노 서브PC(RTX 4060 Ti 16GB, RAM 32GB) 고정값**: H3 `--vram-headroom 1.6`·pinned 켬·`--fast` 금지로 10초·1344×768 약 17분(15초 단일 패스는 메모리 부족 — 2단계 워크플로가 필요해 기본으로 쓰지 않음), 5초·864×480 초안 약 2분 45초. Qwen은 여러 장 편집 때 캐시 `int8`(6장 합성 약 5분). 그래서 이 PC는 「768p·5~10초, 긴 판은 96GB 쪽으로」가 고정값.
- 디노는 스모크를 늘 5초로 하고, 판정은 결과물을 보며 사람이 한다(에이전트는 시간·피크·완주만 잰다).

## 포함되지 않은 것

- 상용 생성 대안(지금은 로컬만), 디노의 화풍·연출 취향, 장비 구매 조언.
- 기동 인자 자체의 설명(`comfyui-agent-basics`·`comfyui-desktop-agent-launch`가 소유).
