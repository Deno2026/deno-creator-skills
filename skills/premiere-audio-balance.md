# 프리미어 오디오 밸런스

## 무엇을 만드나

- 나레이션이 고르게 들리고 BGM이 말을 덮지 않으며 순간 피크가 잘리지 않는 믹스. 프로그램 전체 목표(예: -23 LUFS) ±1 LU, true peak ≤ -2 dBTP.
- 판정 근거: 실제로 내보낸 검증 오디오의 측정값(역할별로도).

## 목적

- 음량이 들쭉날쭉한 컷(다른 날 녹음, 화면 녹화에 섞인 TTS·시스템 소리, 클립마다 다른 원본)을 사람이 클립마다 조절하는 대신, 측정 → 제안 → 적용 → 되읽기 → 출력 측정을 에이전트가 한 바퀴 돈다.
- "누르지 않는다": 평상시 소리를 계속 압축해 평탄하게 만들지 않고, 피크 하나 때문에 클립 전체를 낮추지 않는다.

## 순서

1. **읽기.** 모든 오디오 트랙·클립·원본·현재 레벨과 기존 효과·키프레임을 읽는다. 기존 리미터가 있으면 중복 추가하지 않는다.
2. **측정.** 타임라인에서 실제 사용한 원본 구간의 LUFS·true peak. 나레이션은 **클립 단위**로(한 파일을 덩어리로 재면 섞인 다른 소리가 튄다), 5초 이상 클립은 자체 측정값, 1 dB 미만 차이는 건드리지 않는다. 음악 단독 구간과 주역 삽입음은 foreground, 말 아래 음악은 BGM.
3. **제안.** 역할별 목표에 맞는 정적 gain. foreground에는 순간 피크만 제한하는 하드 리미터(선택적 제한). BGM은 정적 레벨로, 피크 처리가 필요할 때만 리미터.
4. **적용.** 대표 클립에서 효과 추가·값 설정·되읽기를 확인한 뒤 직렬 묶음으로 적용. 사용자 키프레임·기존 효과 보존.
5. **gain 자리.** gain은 `볼륨 > 레벨`에, 리미터의 `입력 증폭`은 0 dB — **Premiere 클립 체인에서 레벨이 효과보다 먼저 적용된다.** 천장은 절대값(예: -3 dB)으로 둔다. 천장을 레벨로 보정하면 피크가 그만큼 더 눌린다(실측 -6.9 → -10 dBFS).
6. **되읽기.** 묶음마다 대상과 값을, 마지막에 클립 수·시작/끝·트랙 구조·길이를 비교.
7. **출력 검증.** 검증용 오디오(WAV)를 실제로 내보내 프로그램 LUFS·true peak와 역할별 수치를 읽는다. 전체 수치는 삽입음 하나의 어긋남을 가린다.

## 시작값(예시 — 청감으로 조정)

| 역할 | 목표 |
| --- | ---: |
| 나레이션 | -23 LUFS |
| 삽입 영상·작품 오디오 | 나레이션보다 2 LU 아래 |
| 말 아래 BGM | 나레이션보다 12~14 LU 아래. 밝은 신스·촘촘한 리듬은 같은 수치에서도 말과 더 부딪히므로 3 dB 더 |
| 장면 전환 효과음 | 순간 최대(M max)를 나레이션의 momentary p90 근처로 — 거의 안 들리게 누르지도, 말보다 튀게도 하지 않는다 |
| 리미터 | 천장 -3 dB, 사전 스캔 7 ms, 릴리스 100 ms, 채널 연결·트루 피크 제한 |

Adobe 효과 파라미터의 raw 값은 표시 dB와 다르다 — 설치된 Premiere의 `adm/HardLimiter.adm`에서 변환 범위를 확인한다(한 설치본: 최대 진폭 `(dB+100)/100`, 입력 증폭 `(dB+100)/150`, 사전 스캔 `(ms-5)/15`, 릴리스 `(ms-40)/160`).

## 갈림길

- `Level만` → 정적 레벨만(리미터 없음). 전체 밸런스의 대체가 아니다.
- `BGM 크다/작다` → 그 BGM 역할만 목표에서 다시 맞추고 프로그램이 ±0.5 LU 안에 머무는지 확인.
- 새로 추가한 리미터 값을 UXP가 time-varying이라며 거절한다 → CEP 경로로 쓰고 UXP로 되읽는다. 사용자 automation을 지워 해결하지 않는다.

## 함정(실측)

- 문장 단위 컷이 남긴 1~10프레임 조각은 측정 도구가 건너뛰어 그 조각만 꺼진다 → 이어지는 클립의 레벨을 물려받게 한다.
- 클립 `오디오 게인`은 audio map에 안 잡힌다 → 확인 믹스가 전 구간 같은 폭으로 빠지면 `.prproj`의 `<Gain>`을 읽고 목표를 게인만큼 옮긴다(게인은 지우지 않는다).
- 한 역할만 크게 낮으면 사용자가 건 오디오 전환(긴 페이드)부터 의심 — UXP에는 전환 목록이 없어 `.prproj`에서 읽는다.
- 효과음 원본이 작아 레벨 상한 +15 dB로 모자라면 나머지를 그 클립 리미터의 입력 증폭으로 올린다(천장은 그대로).
- 사용자가 올린 WAV/BGM은 샘플 단위 끝점을 가질 수 있다 — 프레임 정렬을 강제하면 배치가 막힌다.

## 디노는 이렇게 한다 — 예시

- 딥하우스는 -36 LUFS 그대로, 신스팝은 -36 대비 -3.35 dB(레벨 -27 dB)로 두어야 같게 들렸다.
- 전환 효과음(whoosh)은 레벨 +15 dB + 입력 증폭 +7.3 dB로 7개 모두 M max -21 LUFS 근처, TP -3.0 dBTP.

## 포함되지 않은 것

- 노이즈 제거·EQ·디에서, 음악 편곡, 최종 마스터링 체인(유튜브 정규화는 플랫폼이 한다).
