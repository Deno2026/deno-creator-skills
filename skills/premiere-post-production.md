# 프리미어 후반 흐름

**컷편집이 끝난(또는 통파일을 넘긴) Premiere Pro 시퀀스를 에이전트가 이어받아 유튜브 공개 직전까지** 가져가는 흐름이다. 실행 도구 한 벌은 공개 키트 `deno-creator-skills/premiere`(UXP 플러그인·MCP 서버·도구 스크립트·업로드 헬퍼)이고, 이 편은 그 순서와 판단 기준을 준다.

## 무엇을 만드나

- 오디오가 정돈되고 자막·모션이 얹힌 **4K 마스터 mp4** + 최종 한국어 SRT + 검수된 영어 SRT.
- 유튜브에 **unlisted로 올라간 영상**(한국어·영어 수동 자막, 제목·설명이 지원 언어 전체로 현지화됨). 공개(`public`) 전환은 사용자가 Studio에서 직접.
- 숏폼이면 YouTube Shorts·Instagram Reels(·Threads·X)에 **같은 시각으로 예약**된 게시물.

## 목적

- 사람이 하면 지루하고 실수가 잦은 후반 반복(무음 자르기, 음량 맞추기, 자막 오타·줄바꿈, 설명·챕터·태그, 언어별 제목 번역)을 에이전트가 맡고, 사람은 **판정과 결정**(컷 합격, 최종 자막, 제목·설명, 공개 시점)만 한다.
- 되돌릴 수 없는 일(공개·삭제·결제·로그인)은 항상 사람이 한다.

## 진행 순서와 갈림길

1. **컷.** 사용자가 컷을 끝냈으면 그대로 잠근다. 통파일을 넘기며 "알아서 컷"이면 복제 시퀀스에 **무음 컷 + 문장 단위 다듬기**(했던 말 다시 하기·중복·재시작·실패 테이크)를 한 번에 한다 — 받아쓴 단어를 그대로 잡는 로컬 Qwen3-ASR로 단어를 번호 매기고, 에이전트가 전문을 읽어 지울 범위를 정하고, 경계는 발화 직전 무음에 둔다. 애매한 발화는 남기고 `분:초 + 발화`로 사용자에게 묻는다. 캡션 트랙이 있는 시퀀스에는 ripple 삭제를 쓰지 않는다(빈 구간이 남는다).
2. **오디오.** 구간별 체감 음량을 맞추고 순간 피크만 리미터로 누른다. gain은 `볼륨 > 레벨`, 리미터 천장은 절대값 — Premiere는 레벨을 효과보다 먼저 적용한다. 검증은 실제 출력 오디오의 LUFS·true peak로(짝 편 `premiere-audio-balance`).
3. **모션·자료화면.** 발화 묶음(블록)마다 6칸 연출 메모(발화 의도·시각·실제 자료와 출처·화면 사건·다음 사건·보호 영역)를 쓰고 Remotion으로 렌더해 알파 ProRes로 배치한다. 시각자료는 발화와 직접 관련된 것만. **어떻게 보이게 할지는 채널 연출 기준(사용자 문서)이 정한다** — 비어 있으면 2~3안을 렌더로 비교해 사용자가 고른다.
4. **자막.** 사용자가 Premiere에서 내보낸 SRT의 타임코드가 정본이다. 1단계 타임코드 고정 교정(Whisper 전사와 전수 대조, 에이전트의 한국어 자연스러움 판정) → 2단계 인접 cue 문맥 병합(최대 2줄, 줄 평균 45자 부근)을 캡션 트랙으로 반영한다. 재전사·재타이밍은 사용자가 명시할 때만(짝 편 `premiere-captions-two-stage`).
5. **마스터.** 기본 4K UHD(1080p 시퀀스도 업스케일 — 유튜브가 4K에 더 높은 비트레이트를 준다). 렌더 뒤 해상도·fps·길이를 확인하고 파일 해시와 자막 revision을 한 manifest에 묶는다.
6. **게시 준비.** 업로드 헬퍼(로컬 웹)에 제목 3안·설명 3안·챕터 3종·태그(오타·음차 변형 포함)를 채운다. 설명 고정 블록(추천 링크·커뮤니티·허브·PC 사양)은 사용자의 `channels.json`이 소유한다. 협찬 영상은 브리프를 먼저 받아 키워드를 태그·해시태그로 넣고, "유료 광고 포함" 고지 줄은 넣지 않는다(Studio 체크로 표시).
7. **업로드.** 사용자가 헬퍼에서 `완료 · 업로드 시작`을 누르면 그 화면이 READY가 된다 → unlisted 업로드 + 한국어 자막 → 재조회 → 영어 자막 → 지원 언어 전체 제목·설명 현지화(챕터 개수·타임코드 유지) → 누락 0 확인. 업로드 뒤 설명·태그 수정은 재업로드 대신 revise 도구로.
8. **공개.** 사용자가 Studio에서 수익 창출·미드롤(8분 이상)·유료 프로모션(협찬)을 확인하고 직접 공개한다. 에이전트는 완료 보고에서 "공개해 달라"고 안내하지 않는다.
9. **숏폼.** 세로 완성본과 `publish.json` → 검수(contact sheet·오디오) → preflight 표 → 사용자 승인 → YouTube·Instagram(·Threads·X) 같은 시각 예약. 그 승인은 롱폼 공개 승인과 별개다.

갈림길:
- Premiere 밖의 긴 원본(가변 프레임레이트·재생 끊김) → 무음 구간별 파생 클립을 만들어 배치한다(키트 `long-recording`).
- 자막 없는 영상(시네마틱) → 자막 단계를 건너뛰고 제목·설명 현지화만.
- 대본·클립 생성·BGM 제작이 필요하면 → 창작 상류(ComfyUI 편들)로 돌아가고, 후반은 완성 클립을 받는다.

## 내용 자리 — 사용자가 정하는 것

| 단계 | 사용자 결정 |
| --- | --- |
| 컷 | 합격/불합격, 애매한 테이크 유지 여부 |
| 오디오 | 목표 음량은 청감으로(아래 예시가 출발값) |
| 모션 | 채널 연출 기준(서체·색·리듬) — 첫 영상에서 2~3안 중 선택 |
| 자막 | 최종 문구·싱크(SRT는 사용자가 Premiere에서 내보낸다), 트랙 스타일 |
| 게시 | 제목·설명·옵션 확정, 공개 시점, 채널(기본 채널이 아니면 이름으로 명시) |
| 숏폼 | `publish.json` 승인 |

## 실행 — 로컬(내 PC)

- 도구는 공개 키트 `deno-creator-skills/premiere`(설치 안내는 짝 편 `premiere-kit-setup`). 에이전트는 키트 폴더에서 `AGENTS.md` → 문서 안내판 → 요청에 맞는 workflow를 읽고 `npm run <도구>`로 실행한다.
- Premiere 조종은 UXP 플러그인(읽기·대부분의 쓰기)과 CEP 브리지(효과 수치 등 UXP가 못 쓰는 것)를 파일로 주고받는다. 상시 MCP 등록은 켜 두지 않고 필요할 때만 CLI로 부른다.
- 받아쓰기는 로컬 Whisper large-v3(대조용), 통파일 컷은 로컬 Qwen3-ASR + ForcedAligner. GPU가 없으면 CPU로 느리게 된다.
- 유튜브는 사용자의 Google Cloud OAuth 클라이언트로(하루 기본 할당량 10,000 units).

## 디노는 이렇게 한다 — 예시(참고이지 기준이 아니다)

- 음량 출발값: 나레이션 -23 LUFS, 삽입 영상 2 LU 아래, 말 아래 BGM 12~14 LU 아래(밝은 신스 계열은 3 dB 더), 전환 효과음은 나레이션 momentary p90 근처, 리미터 천장 -3 dB.
- 자막 줄: 평균 45자 부근, 45~50자도 괜찮음, 맥락 우선. 최근 롱폼은 cue의 약 절반이 2줄.
- 마스터는 4K. 편집 시퀀스도 가능하면 처음부터 4K로 만들어 모션을 그 해상도로 렌더한다.
- 설명 고정 블록 순서: 챕터 → 허브 → 추천 링크 → 커뮤니티 → PC 사양, 캠페인 해시태그는 맨 끝 한 줄. 채널이 둘(강의/드라마)이면 드라마 채널에는 강의용 블록을 넣지 않는다.
- 현지화 80여 개 언어는 언어 그룹별로 나눠 번역하고 구조 검사(챕터 수·링크·글자 수·한글 잔존 0)를 통과한 것만 합친다.

## 포함되지 않은 것

- 컷편집 자체의 미학, 채널별 연출 취향·서체 조합, 썸네일 기획(별도 작업공간), 대본·클립·음악 생성(창작 상류), After Effects(사용자가 요청할 때만).
